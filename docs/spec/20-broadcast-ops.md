## 20. 播出运维：停止、监督与运行手册

> 第 20.3–20.4、20.6–20.8 节属于后续阶段，冻结在 [docs/future/spec/20-broadcast-ops.md](../future/spec/20-broadcast-ops.md)。

### 20.1 四层停止

| 层次 | 能做什么 | 不能声称 |
|---|---|---|
| Bellis本地停止 | 撤许可、停Stage、清PCM/字幕/口型、请求游戏撤权 | 已入设备/平台的内容全能撤回 |
| OBS原生/实体键 | 静音指定源、固定安全场景，不经Bellis主进程 | 已入编码/延迟队列的旧内容自动消失 |
| 可选延迟＋强制停流 | 在未发送窗口内丢弃排队输出，具体路径须验收 | 回收已发给平台/观众内容；不影响互动延迟 |
| 独立监督组件 | 租约过期后收权、静音、安全场景或到期下播 | 同机OS整体冻结或OBS崩溃仍绝对可靠 |

OBS官方API区分普通stop与force stop；后者尝试不等待排队数据，前者可能等待发送。[S16] 具体热键、前端操作和全部输出路由必须在目标版本实测，不能把普通StopStream当作丢弃延迟。

当前设计在本地先停止，远端LLM/TTS取消与日志并行。StopOperation只有在声明边界确认时为CONFIRMED；超时UNKNOWN，继续监督和对账，不能把“命令已发”报成静音完成。

上述停止路径和第11.6节共用强制安全入口：业务预算耗尽、数据库满或普通队列过载不能阻塞本地撤权及未知态归约。停止确认缺失时由独立Settlement/Recovery职责继续处理，不因Scene、Attempt或插件已经终态而丢弃责任。本地封锁、OBS应急动作、平台已输出内容分别报告，不把其中一个当成全部停止证明。

P0 仅验证真实宿主、监督、持久化与假设备进程上的有限模拟效果。其独立停止是监督直连端点和端点本地租约，不接入或宣称 OBS、音频、键鼠、平台停止；真实设备路径须由相应阶段另行验收。

### 20.2 监督模式与ExecutionGrant

监督模式、ExecutionGrant 和 StopOperation 的状态、守卫及字段见[P0 契约简报](../generated/P0.md)。stopped 是可由认证操作员明确重新授权的安全静止态；它不证明所有端点已停或所有资源已清理。人工租约与程序连接健康分别记录：心跳只能说明连接在线，不能人工确认、延长人工租约或恢复旧 grant。失联或期限到达先关闭新增效果，监督与端点分别推进停止；恢复必须重新鉴权、确认新实例和适用清理事实并明确授权。

P0 假设备首验采用以下准入边界：

1. 只接受 mode=simulation、只启用 P0 的明确配置，public_broadcast_allowed=false；test_only、public、unattended_approved、P1/未来阶段以及真实媒体、设备和平台能力全部拒绝。RuntimeProfile 的通用结构合法不代表当前 P0 宿主接受启用其中能力。
2. 只加载受信安装清单明确允许的假设备，核验实际入口及全部加载制品、实例、协议与契约摘要、Manifest 和精确能力白名单。SDK 只能识别明确登记的 P0 模拟能力；实际加载和执行入口仍须核验安装信任。自报 simulation 不授予权限，空白名单不是通配。效果仅限自身可观测队列、计数和模拟状态，不加载真实适配器、不注入真实设备/供应商凭据、不开放外部效果路径。独立进程不宣称为恶意代码沙箱。
3. 默认 stopped、无活动 grant。操作员经本机凭据鉴权后明确批准有限 simulation 会话，监督进程、安全通道及端点本地有限租约机制必须已就绪；以认证端点的业务连接就绪事实和实际安全通道核验，不要求预存 ACTIVE grant 或执行 lease，避免首次授权循环依赖。自动验收使用隔离测试操作员凭据，经同一鉴权入口驱动并保存动作；不得增设免鉴权入口，也不将测试脚本视为公开运营中的人工在场证明。
4. grant 固定绑定本次会话、宿主/监督/端点实例、精确监督代次、非空目标与能力白名单、有限效果/队列/期限及适用费用预算。每条执行命令在接纳及实际效果前复核身份、scope、实例、代次、时钟、幂等、余量和授权；异步登记完成后再核验，迟到回执不能恢复已撤权限。固定业务摘要按 P0EffectRegistration 契约绑定完整动作，包括执行节奏；operation 与原期限由完整登记及真实回执独立绑定。
5. 合法首验不要求尚未产生的本次 P0 PASS，仅省去 simulation 对自身验收结论的循环依赖，不省去实际守卫、配置/协议/权限检查与可靠记录条件。首验准入记录和 AcceptanceReport 分开；不得伪造 P0/P8/C0 门禁证据或提供通用 skip-gates。需要可靠登记的模拟效果在记录失败时同样关闭准入。
6. 本地撤权立即阻断新效果。宿主失联、人工/端点租约到期、队列满或存储失败时，独立监督和端点本地机制仍推进停止，不等待业务线程、远端 cancel 或数据库。停止请求、栅栏生效、实际端点停止、清理与可靠记录分别报告。缺少停止/清理证明的范围保持 UNKNOWN 和隔离，不因 stopped、重启、新 scope 或新 operation_id 解除。
7. 重连、重启、测试通过均不恢复旧授权、队列或 Outbox 中的旧执行意图。P0 PASS 只证明当前已声明假设备与 macOS 环境内的行为；真实设备与公开输出继续等待对应阶段。

实际加载字节绑定与权威代次传播遵循第22.6节；新代次不解除 UNKNOWN 资源隔离，也不恢复旧 grant。

监督可以更新端点的有限连接租约，但有效期限不得超过映射后的人工租约、原 grant 截止和时钟映射有效期的最早值。session.renew 只接受认证操作员对当前有效人工租约的明确续租，不改变 supervision_epoch、原执行命令或原 grant 截止，不恢复已撤权或已过期许可。同一 lease_id 固定完整输入，重试不延期、旧 lease 不覆盖后来租约；新的受信 lease 可以传递明确人工续租后的期限，但仍受首次 grant 映射上限约束，监督不得把 heartbeat 当人工续租。具体初始上限由封闭配置给出并进入证据，不把配置值称作实测停止时延。

后续阶段的 test_only 与 public 仍独立于监督模式：前者仅在其真实执行前置满足后允许有限验证，禁止公开输出；后者要求全部适用领域与发布门禁。模式改变必须新授权，不能原地把 simulation 或 test_only 升级为 public。

### 20.5 音画偏移补偿

在OBS最终录制中测Audio↔Subtitle、Audio↔Avatar、游戏源时间关系，记录版本、帧率、采样率、采集路径和voice profile。不得假设VTube Studio在所有机器固定慢几帧。

稳定偏差可对较早轨道增加经验证的音频偏移或视频/源延迟；OBS提供Render Delay滤镜。[S21] 对齐口型后重测字幕；补偿不能消除随机抖动，也不能提前输出尚未生成的媒体。新增缓存计入停止尾音与观众端延迟。
