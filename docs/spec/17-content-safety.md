## 17. 内容安全与合规准入

> 第 17.1、17.3、17.5–17.7、17.9 节属于后续阶段，冻结在 [docs/future/spec/17-content-safety.md](../future/spec/17-content-safety.md)。

### 17.2 ContentGuard契约

输入含双文本/hash、发音/markup/映射版本、已批准前缀与已播事实、受众/活动profile、来源、证据、隐私许可、Provider/voice版本。输出固定为`APPROVED / REJECTED / NEEDS_MORE_CONTEXT / UNAVAILABLE`，附原因码和依赖。

必需检查全部通过才签发审核凭据；超时/不可用不是通过。需要更多上下文时在有限预算内补齐，不能先放行。基础字面、隐私、范围和发音规范化总是需要；公开profile明确哪些语义/读音分类器为必需。

凭据由受信链签发，绑定具体内容/前缀/策略/voice/证据/用途/版本；模型自报safe无效。审核缓存也按这些依赖索引。预审固定模板可以缓存，但加入动态昵称、正文等后重新审实例。任何内容生成之后的发音变换都必须重新绑定。

### 17.4 审核失败与过渡

| 位置 | 原对象处理 | 对观众处理 |
|---|---|---|
| 未播任何内容 | BLOCKED，撤销许可、销毁隔离音频 | 静默跳过或限频安全提示 |
| 已播前缀安全，后续被拒 | 有限边界软收尾，原Utterance ENDED_EARLY | 新建锁定过渡，不把原结果改成功 |
| 当前片段已确认有风险 | 本地硬停，按严重性触发OBS兜底 | 不等句末，不重复拒绝原文 |
| 审核服务失效 | 未审自由内容不放行；已获许可范围受控结束 | 同音色预录/文字提示，暂停新自由话题 |
| 连安全提示都不可输出 | 停止反复生成/重试 | 独立OBS安全场景或停流 |

每事故最多一次自动过渡，连续故障进入安全模式。到边界等待有上限，例如2秒为起始测试值；到界不可确认就硬停并保留不确定范围。不能用`normal seal`洗掉失败，也不能让过渡语完成触发原游戏动作。

### 17.8 审核结果与对象转换

APPROVED才产生内容绑定许可；REJECTED直接到Segment/TextPresentation.REJECTED；NEEDS_MORE_CONTEXT进入WAITING_CONTEXT，只在剩余审核次数和原总deadline内请求允许上下文；预算不够或超时转REJECTED；UNAVAILABLE直接拒绝本次正式输出并记录GUARD_UNAVAILABLE。需要重试时创建有界新审核请求，不延长当前语义对象业务截止。

TextPresentation使用同一四结果流程，但spoken_text=null，不签语音许可。所有拒绝/过期/不可用均有独立事件与原因。内容改变必须产生新草稿/新hash，不能在CHECKING状态偷偷修改已审核文本。新增上下文受PrivacyGateway约束，审核器不能借补上下文获取无关私人记忆。
