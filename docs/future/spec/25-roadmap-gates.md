## 25. 实施路线与发布门禁

> 冻结的后续阶段设计，不参与生成与校验；现行部分见 [docs/spec/25-roadmap-gates.md](../../spec/25-roadmap-gates.md)。

### 25.3 C0公共控制基线与公开/测试门禁

C0是任何真实自动游戏输入的前置，不是P0或无游戏聊天的无条件前置。C0契约可与P3/P4开发并行，完整验收在P5首个自动输入之前完成。只读采集不依赖C0，但绝不把只读接通记为P5完整PASS。

C0至少验证当前目标profile的完整ActionCommand/ControlFrame、四种时域、作用域代次、frame/pulse去重、Effect/Settlement、唯一Broker、部分提交、有限持键、失焦/接管/旧清理隔离。当前profile可只支持点击/短按；未使用的持续/轴/位移字段必须为空或中性，不能删字段或绕Broker。

| 启用范围 | 必需证据 |
|---|---|
| 交流＋投票，不输入游戏 | P0–P4适用出口＋P8；C0/P6/P7/C1–C5可关闭。 |
| 固定剧情有限选择 | P0–P5适用出口、C0 PASS、目标profile真机与P8；连续控制/策略更新不启用则不前置。 |
| continuous_local | C0＋C1＋目标profile/P8完整负载；启用兼容调参加C2。 |
| test_only有限真机验证 | C0及适用P3执行安全出口、操作员批准白名单/期限/效果预算、应急就绪；禁止公开播出。 |

test_only不要求尚未产生的P5真机报告作为P5测试本身前提；正式public必须等待目标P5/P8证据。ExecutionGrant.mode与状态已登记第11.4.18节，不能通过配置布尔量绕过。

C1–C5是按需启用的独立扩展规范，统一维护在本节；核心阶段不因此承担全部扩展实现。

#### C1–C5扩展路线（按启用范围生效）

| 门禁 | 前置 | 必须交付和验收 |
|---|---|---|
| C1 连续本地闭环 | C0、目标profile资源、基础输入安全与有界真机测试许可 | 一个固定移动/镜头场景，先简单后端；新观察闭环、健康退出与全负载。可选候选修正仍需第14.11/15.15节；学习组件另需C4。 |
| C2 兼容策略更新 | C0及所用已验证后端（waitable_step需P5，continuous_local需C1） | PolicySchema、base CAS、本地边界、五终态、取消和查询；Task/Attempt不中断，旧后缀拒绝。 |
| C3 模式与定位覆盖复用 | C0及所扩展模式的P5/C1/C2 | 新页面/语言/DPI/视角逐profile验证；grounding只提升感知覆盖，不自动扩大控制授权。 |
| C4 学习后端 | 对应模式已有基线，独立数据用途/隐私门禁及有界实验许可 | 解耦策略、区域重排、编辑器/critic各自记录数据与制品版本；固定留出、简单基线、真机/全负载和批准。不在线自动训练或部署。 |
| C5 局部预测 | 已验证闭环及可测局部响应模型 | 预测只执行短当前部分，按新观察更新；比较误差、退出和维护成本，不强制训练或MPC。 |

只读使用已经批准的外部定位／重排模型，按P5的来源、外发、资源和质量门禁验收，不要求先开展C4训练；本地训练或微调定位组件时才追加相应C4数据与制品门禁。只读实验本身不需要输入C0，C0仅在实际自动输入前要求。

这些是启用条件，不是通用游戏智能等级。研究路径之间没有默认串行依赖：C1可以只用规则，DEM式技能可以不使用编辑器，RankGround式定位可以不使用学习控制器。学习后端真机实验凭已有C0和受限test_only许可进行，实验完成后再申请该制品的公开准入，不以未产出的自身报告造成循环前置。

每个后端固定启用算法、实际模型调用链、ActionSchema/Profile、版本/时限、资源、Effect/Settlement和失败出口。没有足够数据或硬件收益时保留简单实现；关闭C1–C5不阻塞已验证剧情首播。S36–S39只提供方法启发，具体Bellis准入由当前契约决定。

动作算法、帧合成、实际前缀、兼容参数应用、健康续租和原始示范由Game Runtime/离线工具管理；Bellis只接公共契约、语义投影与必要诊断。完整离线治理见第23章。

### 25.8 证据、计算与恢复工作包

| 工作包 | 最早阶段／输出 | 独立验收与停止条件 |
|---|---|---|
| W-1 根证据与派生视图 | P5只读；VisualObservationRef／DerivedView、固定回映、目标绑定 | 坐标及来源正反例＋真实DPI验证；根捕获不可靠时停止自动选择。 |
| W-2 指定目标定位 | P5；简单基线与可选区域定位适配 | X-G；不满足缺失／歧义拒绝和目标覆盖时不启用指针自动输入。 |
| W-3 失败信息与恢复上下文 | P3记录、P6采用；ReflectionRecord／RecoveryContextView | X-R及跨分支/删除测试；不能正确筛选就仅操作员可读诊断。 |
| W-4 计算复用 | 相应P3/P5/C1后端内部；ComputeArtifact及预算 | X-D；依赖难以完整刻画或收益不足时禁用缓存，不改变正确性路径。 |
| W-5 有限真实恢复 | P6；RecoveryCapability／Proposal／Result、保护平面 | 已提交／UNKNOWN／读档失败／重启测试；不支持时明确UNSUPPORTED并人工处理。 |
| W-6 执行前修正 | C1实验，学习型另需C4；候选／前缀／修正policy | X-E；prefix不可核验、动作非连续或未证明收益时保持关闭。 |

每个工作包在独立小范围变更中提交职责、Schema与假实现／实际适配测试；不得一口气启动四种训练工程。试验结论可为“保留简单基线”，这同样是有效交付。
