## 18. 长期记忆与隐私（Iris）

### 18.1 长期记忆不是事实和权限的后门

默认只保留当前会话必要上下文。公开弹幕中出现个人信息，不自动授予永久保存、跨平台关联或将来公开复述许可。健康、关系、学校/单位、详细所在地等按必要性和许可筛选，无适当依据不长期写入。

| 来源 | 默认解释 |
|---|---|
| self_public_output | 贝莉实际说过，不等于内容客观正确 |
| verified_fact | 有可信证据/操作员批准的事实，仍带有效范围 |
| viewer_claim | 某观众声称；重复、总结或多账号附和不升级成事实 |
| game_observation / testimony / inference | 分别为观察、证词和推测；绑定story_scope/存档范围 |

来源与派生关系贯穿总结、向量化、合并、整理、备份和导出。人格核心配置、权限和读音词典不能被“你上次答应过”式记忆回写覆盖。

### 18.2 最小元数据和检索前过滤

记忆含memory_id、主体平台范围、来源/证据、可信等级、可见性、用途、许可/撤回依据、story_scope、保留期、派生关系、删除代次和审计引用。

可见性至少区分`public_broadcast / session_only / private_subject / operator_only`；用途区分live_context/public_recall/personalization/analysis。身份来自平台稳定ID，不以昵称或跨平台同名自动绑定。

```text
检索意图 → 认证主体＋当前公开用途 → PrivacyGateway确定ACL/范围
        → 检索端先过滤 → 最小证据进入模型
        → 输出侧再核验公开许可 → 才可正式播出
```

不能先把B的私人记忆送给主控再要求它保密。检索索引若不支持必要范围过滤，该用途禁用或采用经验证的隔离索引，不靠提示词补洞。观众A不能获得B的私人经历。

### 18.3 外发、写入与双写禁止

LLM、Embedding、Rerank、TTS和评审模型外发都受PrivacyGateway检查，不能只管Iris数据库。数据条款、地域、留存、训练用途与同意按Provider配置核验；默认不将互动数据用于训练。

集成模式仅Bellis管理Iris语义写入owner；游戏侧交引用/事件，不绕过网关直写。异步写入使用必要持久待提交记录、幂等键和有限队列；断连降级本场上下文，不阻塞播放或游戏快闭环。

### 18.4 删除与恢复竞争

经身份核验的删除/撤回先登记本地deletion_tombstone，阻止相关召回、公开输出和未提交写入，再异步清理原文、向量、缓存、摘要/派生项、待发记录和控制范围内导出。

写入和删除代次比较必须原子或按受信顺序归约，旧异步结果不能在删除之后复活。备份恢复先应用最新墓碑再开放检索；无法立即清理的备份/法定保留项隔离并记录期限。日志最小化且不能再次进入主播上下文。

删除完成说明分列在线存储、派生/备份待处理、供应商可执行请求与无法控制的平台录播/观众副本。不能承诺全网抹除、供应商模型遗忘或已播事实从未发生。

### 18.5 接入门槛

Iris公开召回前测试：跨用户/用途隔离、viewer_claim不升级、总结保留来源、删除与并发写入、缓存/摘要清理、恢复墓碑、外发拒绝、默认不跨平台关联、失联时本地先阻断。未通过时关闭长期写入和公开召回，不先上线再补隐私。

### 18.6 任务局部反思与恢复上下文

ReflectionRecord默认仅属于当前任务用途，不自动写入Iris。它引用原Goal、Observation、ExecutionJournal和Attempt，不维护第二套权威事实。操作经验、剧情知识与诊断假设分别分类；evidence_backed条目需证据与受信复核，hypothesis不能因重复生成被提升。

RecoveryContextView只列通过筛选的`record_id + item_id`，以及当前Goal和恢复后新Observation引用。未审核、证据失效、用途不符、删除代次落后或超出可见story_scope的条目不能进入视图。读取底层条目时再次过滤，不能先把全文送入LLM再要求它保密。

视图受最大记录数／条目数／字节或Token预算约束；更新采用有界替换，不无限追加聊天历史。默认不保留长期跨会话诊断；确需升为Iris记忆，另走PrivacyGateway的来源、用途、保留和删除门禁，不能借“学习过的经验”绕开。

### 18.7 跨分支经验、缓存和删除

同一条失败经验只有在依赖独立于被丢弃剧情分支、当前用途获准且经受信复核后，才可以跨scope复用。包含未来剧情事实、答案、角色结局或由它们推出的策略，保留最严格来源范围；摘要或改写不自动去除派生限制。

story_scope可见性由Game Runtime／隐私策略提供显式允许集合。读取旧存档后，操作员审计仍可查看授权范围内的历史，但新的规划上下文只可使用当前允许信息。模型自己给出的“通用经验”分类不授予跨分支传播权。

删除墓碑先阻断ReflectionRecord、RecoveryContextView和ComputeArtifact的读取，再清理在线、派生、缓存及待提交项。恢复快照、旧上下文和延迟模型结果不能覆盖最新墓碑或恢复旧公开召回权限。对账与必要审计的保留范围仍按第18.4节说明，不承诺已播内容从未发生。
