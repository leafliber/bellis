### 24.6 控制能力专项实验矩阵

| 场景 | 必须观测 | 不能据此宣称 |
|---|---|---|
| 一个可等待菜单/剧情选择 | 先C0=PASS，再测新观察、单步动作、语义/Effect/清理、评论与选择同步 | 可以跳过C0，或已会连续移动/战斗 |
| 已覆盖局部移动/镜头场景 | 持续新观察纠偏、目标/模式变化、失锁与停止 | 已覆盖任意陌生游戏 |
| 高层延迟/断网，局部后端健康 | 现有闭环持续或按权限期限退出 | 上层/监督可以永久不存在 |
| 采集冻结但控制线程仍活 | 有效观察到期撤权；不靠alive续租 | 任意图像hash重复都异常 |
| 策略更新与输入竞争 | base冲突、effective_seq、旧尾部隔离、回执失联查询 | 多进程/多机原子副作用 |
| 高负载下快策略推理超时 | 原始观察年龄、拒绝、降级/接管、音画连续性 | 用空tick维持标称Hz就是达标 |
| 同时输入和人工接管 | hold清理、增量/脉冲去重、旧owner回执拒绝 | 仅API接纳就证明游戏效果 |
| 可选示范记录/权限撤回 | 最小采集、来源与时钟对齐、样本gap、删除传播 | 录像天然是专家数据或模型已遗忘 |

对照组可包括逐步VLM、选择性分块、规则本地闭环＋异步策略、学习策略，局部预测后端仅在前提满足时加入。固定任务、动作协议、输入/证据来源、设备/版本、输出预算和直播负载，报告全部失败、拒绝、接管及测试未覆盖范围。

录制回放适合测感知、格式、策略候选与输出依据；改变输入后的真实游戏结果必须通过真机/合适环境闭环测试。训练集/留出集与测试场景差异明确，不能以相邻帧相似度夸大迁移。Shadow模式不注入输入、不中途抢夺真实玩家控制。

### 24.7 自主覆盖、内容与观众质量

活动闭环完成率、人工接管率/原因、自动恢复成功率、无进展等待时长、页面/流程覆盖范围与未支持能力必须报告。没有错误输入不等于能持续推进节目。

回放评估重复率、回复相关性、人设与诚实、合格候选用户覆盖、公平性、证据支持与剧透、韵律/发音、前后衔接、游戏共声和私人信息泄漏。人工抽样优先，LLM评审只辅助；正确AI声明与不确定性不计人设失败。

安全/隐私是独立门槛，不能被低延迟或娱乐性总分抵消。比较固定任务、输出范围、模型/voice版本和负载；失败请求和接管全部保留分母，不通过大量跳过消息获得漂亮平均值。
