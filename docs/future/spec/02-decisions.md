## 2. 关键设计决策

> 冻结的后续阶段设计，不参与生成与校验；现行部分见 [docs/spec/02-decisions.md](../../spec/02-decisions.md)。

### 2.5 执行与交付决定（D01–D12）

| ID | 当前决定 | 规范入口 |
|---|---|---|
| D01 | Activity级对账与局部incident分离；对账后可继续原活动阶段或完成收尾。 | 第7.7、11章 |
| D02 | deadline/timeout是独立触发事实；STOPPING允许真实自然完成；结果由契约和最终水位确定。 | 第6.9、7.9、11.5节 |
| D03 | 人工确认与行政结案分开；未知结案保留墓碑，资源复用另需清理/退役证明。 | 第7.8节 |
| D04 | Utterance软收尾同归约关闭追加，等待Stage尾部栅栏；QUEUED可进入UNKNOWN。 | 第11、12章 |
| D05 | 主控记录使用完整Action或登记候选引用；不保留缺字段自动补齐与task.spawn双路径。 | 第5.6、12.2节 |
| D06 | PlanDraft/PlanSpec、全部节点、谓词、失败处理器、完成契约统一登记；取消服务join字段。 | 第6章、附录B |
| D07 | 投票平票在预先采用图中明确最多重开一次；两轮共享业务Effect范围。 | 第16章、附录A.2 |
| D08 | ControlFrame统一嵌套context_versions/deadline；hold从生成时刻起算，重包不续期。 | 第14.6节 |
| D09 | 所有PolicyUpdate终态都可靠通知；新增cancel_policy_update，应用中不乐观取消。 | 第13.2、15.13节 |
| D10 | 代次、错误、事件、监督和ExecutionGrant全部登记；test_only不升级为公开许可。 | 第4.11、11章、附录B |
| D11 | P0缩为基础规范和安全骨架；按阶段/profile实现状态机与不变量，C0独立作为自动输入前置。 | 第24、25章 |
| D12 | Stage持久设备配对与短期连接许可分离；规范正文按章分文件，生成表与校验可复现。 | 第19、22章 |

### 2.6 证据、计算与恢复决定（D13–D24）

| ID | 当前规范取舍 | 规范入口／最早实现 |
|---|---|---|
| D13 | 根观察、派生视图、定位结果保留同一来源链；裁剪／推断／缓存不刷新证据年龄。 | 第4.8、4.12、13.9节／P5 |
| D14 | 规划决定选谁，定位器只回答在哪里；无目标、歧义、证据不足和过期均不是可执行坐标。 | 第13.9–13.11节／P5 |
| D15 | 指令语义、视觉现场、授权分频处理；缓存命中不等于现场新鲜或租约有效。 | 第4.13、15.14、21.10节／P3后按后端启用 |
| D16 | 执行前修正在PolicyBackend内产生新候选，只能修改未提交且获准修正的连续动作后缀。 | 第14.11、15.15节／C1；学习方法另需C4 |
| D17 | 已提交前缀来自Broker账目；价值、排名与反思得分都不签发权限或证明效果。 | 第14.11、15.15、17.9节 |
| D18 | 失败反思是有来源、有条件的任务局部计算产物；当前现场从新观察重建，不由失败分支复写。 | 第7.10、10.7、18.6节／P3记录，P6采用 |
| D19 | 恢复明确when／where／what及真实可恢复范围；有副作用的恢复仍是受控Action。 | 第10.7–10.10节／P6 |
| D20 | 业务历史、安全授权、删除墓碑和累计预算不进入恢复快照；终态对象不复活。 | 第10.8–10.10、22.7节／P6 |
| D21 | 跨剧情分支先过滤再入模型；通用操作经验与剧情知识分开，不能通过摘要洗掉剧透。 | 第13.6、18.6–18.7节／P5/P6 |
| D22 | 先简单后端、再计算复用、最后按证据选择学习／修正；局部计算职责不新增执行权威。 | 第3.4、15.16、25.4节 |
| D23 | 四组实验独立比较质量、拒绝率、完整负载、尾部延迟与费用，不预设复杂模型一定胜出。 | 第21.10、24.10、25.8节 |
| D24 | P0和首播前置不扩大；扩展结构可以先登记，启用时才要求对应实现和门禁。 | 第24、25章 |

### 2.7 论文事实与项目设计的边界

| 来源／固定版本 | 原文支持的方法与限制 | 本项目设计落点 | 最早阶段 | 不直接采用 |
| --- | --- | --- | --- | --- |
| Real-Time EXPO-FT / 2609.18207v1 [S36] | 慢候选与最新观察下的有界编辑、价值选择分开；依赖学习适配，非现成游戏输入后端。 | D16/D17；第14.11、15.15、23.6节 | C1；训练型另需C4 | 不移植机器人动作空间／训练结果，不在线改权重。 |
