这些材料保留当时的计划和验证经过，不代表当前完成状态或下一步任务。当前入口为 [能力状态](../reference/current-status.md) 与 [双线路线图](../plans/README.md)。

归档不撤销协议或兼容性决策，ADR 编号不重用。只修正必要导航；新实现经过写提交/PR，状态更新到相应主题，避免不断复制完整日志。
