# Stage、OBS 与形象

Stage 是运行在 OBS 浏览器源里的页面，负责播放音频、显示字幕，并回报播放游标。Stage 服务与 OBS 控制属于关键平面；形象（VTube Studio）是普通插件。P0 用模拟 Stage 与模拟 OBS，P1 接真实 OBS。

## 职责

- **Stage 页面**：接收已授权的音频与字幕，用 AudioWorklet 播放，回报播放游标、欠载与完成。
- **Stage 服务**（宿主内）：提供页面、管理连接与认证，只转发带有效 Stage 音频输出许可令牌的音频。
- **OBS 控制**（宿主内）：经 obs-websocket 切场景、静音源，每次操作都需持有执行许可。急停不走这里，走安全核自己的 OBS 应急连接。
- **形象**：按播放游标驱动口型，并管理表情与待机动作。
- **公开展示层**：投票、致谢等只读信息，与 Stage 分开。

## 不负责

决定说什么、审核、合成。Stage 没有键鼠能力，也不能提交自由内容。

## Stage 页面

- **加载方式**：推荐由宿主经 loopback HTTP 在固定端口提供页面，作为 OBS 浏览器源的 URL 加载（R-08）。AudioWorklet 与 WebCrypto 都要求安全上下文；OBS 的“本地文件”模式由 OBS 合成来源，是否算安全上下文没有保证，因此不用。是否满足以探针 S-01 为准。
- **连接**：推荐 localhost WebSocket，用一次性会话令牌认证；页面 URL 不带长期凭据（R-08）。音频用二进制消息，控制用文本消息。
- **播放**：PCM 经 MessagePort 送入 AudioWorklet 的环形缓冲，不依赖 SharedArrayBuffer（它要求跨源隔离，在 OBS 浏览器源中是否可用由 S-01 验证）。欠载时补零，但补零不推进播放游标。
- **令牌校验**：页面只播放带当前许可令牌的音频；令牌变更后，旧令牌的缓冲立即丢弃。令牌消息带许可时长，续约时重发；页面在时长内收不到续约即视为许可过期，自行停止并清空缓冲。
- **播放游标**：页面回报每句的实际开始、已播采样数、结束与截断（定义见[发声](speech.md#播放游标与写回)）。字幕与口型随游标推进，而不是随文本到达或墙钟推进。`getOutputTimestamp()` 在 OBS 接管音频时究竟对应哪个时钟，由 S-01 实测；与推流混音之间的偏差在 OBS 录制回环中校准。
- **自保护**：收不到宿主心跳时自行静音并清空缓冲；收到心跳即应答。Stage 服务在截止时间内收不到应答，视为 Stage 不可用，安全核走急停路径（D-30）。
- **字幕安全**：只显示经发声管线放行的字幕文本，用 `textContent` 渲染，不解析 HTML。
- **AI 标识**：试播起，页面常驻 AI 生成内容标识；标识层不可见即视为不可播出（D-09，见[合规](../compliance.md)）。

## OBS 配置要求

- 推荐 Stage 浏览器源开启“Control audio via OBS”，使 OBS 的静音和切场景能直接控制 TTS 声音（R-09）。
- 不开启“Shutdown source when not visible”，避免切场景时页面被卸载。
- Win11 在 OBS 最小化或被遮挡时可能节流定时器，已有浏览器源音频失真的报告（[obs-browser #406](https://github.com/obsproject/obs-browser/issues/406)）；长时间运行的影响由 S-01 实测。
- 基线版本 OBS 32.2.x（D-24）；OBS 与浏览器内核版本写进 Stage 握手，便于对照兼容矩阵。
- 安全场景与静音目标在配置中固定，开播预检确认它们存在。

## 形象

- 推荐经 VTube Studio API 注入参数（R-15）。口型按播放游标计算，注入频率不低于 30Hz，并保持每秒一次心跳，否则 VTS 会认为参数丢失。
- 不把 TTS 音频再交给 VTS 的麦克风口型，避免两条路径不同步。
- 一个参数只由一个插件写入；检测到被其他插件占用时报告，不抢写。
- 音画偏差在 OBS 录制中实测，必要时用 OBS 的渲染延迟补偿，不提前输出尚未生成的内容。

## 公开展示层

投票、致谢、提示等观众可见信息放在另一个来源的页面，只读公开数据，没有控制能力和私密数据。

## 验收

| 阶段 | 内容 |
| --- | --- |
| P0 | 模拟 Stage：游标回报、欠载不推进游标、旧令牌音频被丢弃、心跳丢失自静音、会话令牌认证 |
| P1 | 真实 OBS 32.2.x：安全上下文与 AudioWorklet 可用；最小化或遮挡 30 分钟的欠载与漂移；停止到静音时延；字幕与口型偏差 |
| T1 | AI 标识常驻；开播预检通过 |
