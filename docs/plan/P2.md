# P2 任务卡：真实互动

**目标**：B 站开放平台的真实弹幕经分诊交给真实决策模型，回应经发声仲裁真实播出；投票、Iris 记忆的召回与写入、本机操作台、OBS 热键急停与遥测接入；断线、故障与重启都不重做副作用。

**平台**：在 Windows 11 x64 真机上验收（D-11）；Iris 以 Docker 部署在同一台机器（D-23）。Windows、macOS、Linux 三平台 CI 照常运行完整检查并必须通过；模拟通过不等于真机通过。

**必读**：[愿景](../vision.md)、[总体架构](../architecture.md)、[观众接入与投票](../modules/audience.md)、[决策模型](../modules/director.md)、[发声](../modules/speech.md)、[记忆](../modules/memory.md)、[运维](../modules/operations.md)、[安全核](../modules/safety-core.md)、[插件内核](../modules/plugin-kernel.md)中的权限一节、[审核插件](../modules/moderation.md)中的开关一节、[真机探针](spikes.md)、[合规](../compliance.md)中与 B 站、模型备案、观众个人信息有关的条目。

## 范围

做：Iris 与决策模型的真机探针；B 站开放平台弹幕接入；真实决策模型；真实弹幕下的发声仲裁与 MiniMax 限流时的等待；投票；Iris 召回与写入；本机操作台与 OBS 热键急停；遥测；开播预检中 P2 相关的项。

不做：
- 游戏桥与 Game Runtime（P3）。
- AI 标识与合规门禁（T1）；打包与分发（R-22）；M3。
- Iris 的事件流提醒，以及个性化与私密召回（D-10）。
- 观众删除请求的核验流程：P2 只做操作员登记的本地墓碑。

暂缓（不阻塞 P2 的出口，条件具备或出现相关问题时补测）：
- 真实直播中的连续测试：在 M1、M2 下连续直播，以及只能在开播状态下才能测的项。
- B 站真实平台的测试：入驻直播开放平台、录入 `bilibili` 与 `bilibili-code`，以及维护者直播间的真实弹幕经开放平台到达分诊。P2 中弹幕接入只在本机伪开放平台上验证，真实链路的弹幕用录制回放注入。
- 真实审核模型与探针 S-08（R-12）：审核插件在真实 profile 中显式关闭，只保留开关接口与模拟实现。
- 投票与提示的画面展示层（[公开展示层](../modules/stage.md#公开展示层)）：P2 只口播；礼物、SC、大航海的致谢。
- P1 中暂缓的火山引擎 TTS 与云端主备，仍按 [P1 任务卡](P1.md#范围)。

## 步骤

1. **真机探针。** 跑 S-09 与 S-11，方法与记录要求见[探针](spikes.md)。
   - S-09 需要 Iris 已部署、令牌已录入；S-11 需要方舟 API Key 已录入、外发已同意。
   - 第 3 步看 S-11，第 6 步看 S-09。S-11 中 GLM-5.3-flash 的时延或结构化输出不达标时，交维护者决定是否换型号（R-17）。

2. **弹幕接入（R-18）。**
   - 按[观众接入](../modules/audience.md#接入)实现开放平台的接入插件：签名、开启与关闭项目、项目心跳、长连接（认证、心跳、解包、地址轮换）、场次失效与重开。
   - 接入插件只负责收发，持有 `secret:bilibili` 与 `secret:bilibili-code`；分诊不持凭据（见[插件内核](../modules/plugin-kernel.md#权限)）。
   - 弹幕写成持久事实后交给分诊；礼物、SC、大航海、点赞只记为事实。断线、心跳失败与场次失效记录缺口。
   - 用本机的伪开放平台（HTTP 与长连接）做自动化测试，覆盖签名、解包、心跳超时、场次失效与重连，在三平台 CI 运行。

3. **决策模型（R-17）。**
   - 实现模型客户端插件：OpenAI 兼容的 Chat Completions，流式读取，不做隐式重试，取消即断开；按 S-11 的结论设置思考档位与结构化输出方式；外发按主机授权。
   - 决策插件按[决策模型](../modules/director.md)组装上下文、合并与取消决策时机、校验意图；输出先整段解析，弹幕到首音不达标时再改为增量解析。
   - 连续失败降级并提示操作员；人设漂移检测给出信号。
   - 用录制的 SSE 夹具测流式解析（保活注释、多行数据、流中途出错、结束标记），在三平台 CI 运行。

4. **发声。**
   - 发声仲裁在真实弹幕负载下排队、过期与抢占（[发声仲裁](../modules/speech.md#发声仲裁)）。
   - 云端 TTS 按[限流](../modules/speech.md#云端-tts)的规则在 MiniMax 到每分钟上限时安静等待。

5. **投票。** 按[投票](../modules/audience.md#投票)实现：决策模型发起，规则在开始时冻结，弹幕计票，平台缺口单独记录；题目、选项与结果由角色口播；结果作为可对账的副作用，重启后先查状态再补记。

6. **记忆（R-19）。**
   - 按[记忆](../modules/memory.md)实现 Iris 客户端（只负责收发，持有 `secret:iris`）与记忆插件（隐私网关、召回过滤、本地墓碑，不持凭据）。
   - 召回带硬超时，超时就不带记忆继续决策；写入只含观众实际听到的部分，观众消息标为不可信，去重键持久保存，失败进入有界的待发队列。
   - 墓碑经 `pnpm operator` 登记。

7. **操作台与物理急停。**
   - 按 R-20 实现本机操作台（见[运维](../modules/operations.md#操作台)），含 M1 的逐句放行与否决、插件状态与告警、审核开关的常显。
   - 按 R-27 让安全核订阅 OBS 的场景与静音变化，OBS 热键按下即进入安全停止（见[安全核](../modules/safety-core.md#执行许可与急停)）。
   - 令牌重放、错误的 Host 与 Origin、缺 CSRF 令牌的写请求的拒绝有自动化测试，在三平台 CI 运行。

8. **遥测（R-21）。** 实现 `traceparent` 的生成与透传（含 sidecar 的 JSON-RPC），span 与关键直方图写入 JSONL（见[观测](../modules/operations.md#观测)）。

9. **开播预检与真实配置。** 实现开播预检中 P2 相关的项（弹幕接入、决策模型、Iris 就绪），真实配置与 profile 的样例加上这些插件并显式关闭审核插件，只含脱敏占位值。

10. **仿真与实测。**
    - 确定性仿真加入新场景：弹幕断线与缺口、模型超时与非法输出、投票跨重启、Iris 超时与写入失败、MiniMax 限流等待、OBS 热键急停；不变量随之扩充。
    - 在真机上完成下面出口中的全部实测与演练，结果写入 `reports/`。

## 出口

以下全部在 Windows 11 真机上实际运行通过，且三平台 CI 绿：

**平台**
- 全部测试与固定种子仿真在真机上重跑通过。
- 新增的凭据（`bilibili`、`bilibili-code`、`ark`、`iris`）只经录入命令写入，不出现在日志、事件和报告中（`pnpm secret audit` 在会话进行中与停止后各核对一次）。

**弹幕与决策**
- 弹幕接入在本机伪开放平台上：长连接断开、项目心跳失败与场次失效后自动恢复，缺口如实记录（真实平台暂缓，见范围）。
- 弹幕到首个音频实测，对照[时延目标](../architecture.md#时延目标)：弹幕由录制回放注入，经真实决策模型、TTS 与 OBS 播出；平台投递的时延不计入。
- 决策模型的超时、出错与非法输出被丢弃，连续失败降级并提示操作员；取消后不再有输出。
- MiniMax 到每分钟上限时安静等待，不换音色、不降级，额度恢复后继续。

**投票与记忆**
- 投票规则在开始时冻结，只计截止前收到的有效票，平台缺口单独记录。
- Iris 召回超时时不带记忆继续决策；只召回直播间入口内的公开事实；写入只含已播出的部分；本地墓碑阻止召回与待发写入。

**操作台、急停与重启**
- 操作台可用，M1 下逐句放行与否决生效；审核插件显式关闭，操作台常显“审核已关闭”，状态记入事件。
- OBS 热键按下到宿主进入安全停止的时延实测；宿主卡死时 OBS 热键仍能切到安全场景并静音。
- 重启不重做副作用的演练：在发言、投票、Iris 写入进行中强制结束宿主，重启后不重播、不重复开票、不重复写入。

**观测**
- 一条弹幕从接入到播出的链路追踪完整，跨进程处带同一 trace；关键直方图写出。

实测指标报告样本数与 p50/p95/p99，失败样本不剔除；目标数值在实测前仍为 PENDING。
