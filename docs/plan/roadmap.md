# 路线图

阶段顺序已批准（D-25）。每个阶段有明确的出口；三平台 CI 只证明代码在各平台上能通过检查，阶段验收只在指定平台上实测才算数，模拟通过不等于真机通过。每个阶段开工时写任务卡，范围超出任务卡时先找维护者确认。

```text
Bellis：      P0 内核与安全核 ─► P1 真实媒体 ─► P2 真实互动 ─► P3 游戏桥与魔女审判 ─► T1 公开试播
              (macOS，全模拟)    (Windows)       (Windows)       (Windows)                 │

                                                                                                    │
                                                                                                    ▼
```

## P0 内核与安全核

- **验收平台**：macOS。
- **内容**：插件内核、安全核、状态存储、外部看门狗（对接模拟 OBS）、一条全模拟的端到端发声链路、确定性仿真（D-14、D-26）。
- **出口**：见 [P0 任务卡](P0.md)。

## P1 真实媒体

- **验收平台**：Windows 10/11 x64；P0 的全部测试在 Windows 上重跑通过。
- **内容**：OBS 32.2.x 中的 Stage、云端 TTS 与本地降级 TTS sidecar、VTube Studio 形象、真实 OBS 控制与看门狗、DPAPI 加密存储；固定文本可以真实发声、出字幕、驱动口型。
- **前置**：R-08–R-11、R-15 已批准；[探针](spikes.md) S-01、S-02、S-03、S-05、S-06、S-07、S-10 有结果。
- **出口**：停止到静音、急停到安全场景的时延实测；字幕与口型偏差实测；OBS 最小化或遮挡下长时间播放无失真；sidecar 崩溃与恢复演练。

## P2 真实互动

- **内容**：决策模型、审核插件接入真实审核模型、B 站直播开放平台接入（测试直播间）、分诊、真实发声仲裁、投票、Iris 只读召回、操作台、遥测。
- **前置**：R-12、R-17–R-21 已批准；探针 S-08、S-09 有结果。
- **出口**：私有测试直播间中，在 M1 与 M2 下完成连续直播；弹幕到首音实测；审核插件开与关两种状态都演练过；重启不重做副作用的演练。

## P3 游戏桥与魔女审判

- **内容**：与 Game Runtime 冻结游戏桥契约；Game Runtime 完成《魔女审判》适配（采集、OCR 与 VLM 插件、输入代理、决策点）；决策模型处理投票或自选。
- **前置**：探针 S-04 有结果。
- **出口**：私有测试直播间中完整推进一段剧情；无计时选项的投票或自选、有计时选项的自选都正确执行；急停后全部输入释放的时延实测。

## T1 公开试播：《魔法少女的魔女审判》

- **形式**：B 站小流量公开直播，AI 自主游玩，操作员全程在场（M2）（D-06）。
- **门禁**：
  - [合规](../compliance.md)中全部“试播”项满足；
  - 开播预检通过；
  - M2 下的急停与看门狗演练记录；
  - 审核插件的启用状态由操作员确认并记录；
  - Iris 外发配置核对。
- **产出**：真实观众下的时延、弹幕分布、降级数据（审核启用时还有判定数据），作为后续阶段的输入。

## Game Runtime 并行线

- **VLA 研究**（D-05）：在 Game Runtime 中离线推进，与 Bellis 的 P0–P3 并行。内容包括同步采集工具（画面 + 键鼠 + 口述）、快策略原型、首动作时间与输入释放测试、原神离线评估。不进入直播。
- **魔女审判适配**：在 P3 与游戏桥对接。
- **原神**（D-03）：AI 作为玩家自主游玩，从最基础的能力搭起，按“探索与剧情 → 解谜与小游戏 → 战斗”分步上线。每一步开播前复核米哈游协议与账号风险（见[合规](../compliance.md)），并根据 GPU 实测决定是否加推理机（D-22）。

## 无人值守

在 M3 门槛（见[安全核](../modules/safety-core.md#监督模式)）全部满足后，逐步减少人工在场的要求；先在能力收窄的 profile 下试行。
