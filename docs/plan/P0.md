L2 只做规划、派发、审查、集成和验收；实现、测试与文档交给 L3。阶段使用独立 worktree /Users/cassia/.codex/worktrees/7e91/bellis，在继承基线 204df03257aac650801a6c78c86d75a39ddb522e 上使用 dev/p0-safety。原工作区仅可读取核对，不在那里修改；不重建或改写继承基线，不读取/复用旧分支，也不处理其它 worktree。

通过 PR 交付，不自行合并。后续文档/契约与实现分开提交，生成物随源提交，逐路径暂存，禁止 git add .；不整体 squash 混合提交边界。每包交回后 L2 亲自审查并运行完成标准，每次集成 pnpm check。
