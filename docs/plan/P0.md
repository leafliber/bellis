# P0 任务卡：内核与安全核

**目标**：在全模拟环境中证明内核成立。插件按依赖激活、停用前安全收尾；所有对外动作经安全核授权；一条完整的发声链路在模拟设备上跑通，急停可证，重启不重做副作用。

**平台**：在 macOS 上验收。Windows、macOS、Linux 三平台 CI 运行完整检查并必须通过；代码从第一天起不依赖 POSIX 专有语义（见 [Windows 平台](../platform/windows.md)）。

**必读**：[愿景](../vision.md)、[总体架构](../architecture.md)、[插件内核](../modules/plugin-kernel.md)、[安全核](../modules/safety-core.md)、[状态存储](../modules/state-store.md)、[发声](../modules/speech.md)、[Stage、OBS 与形象](../modules/stage.md)、[决策模型](../modules/director.md)、[观众接入与投票](../modules/audience.md)、[运维](../modules/operations.md)中的确定性仿真一节。

**开工前置**：R-01–R-07、R-14、R-23 已在[技术基线](tech-baseline.md)中批准。未批准的路线不得在实现中写成定论。

## 范围

做：插件内核、安全核、状态存储、外部看门狗（对接模拟 OBS）、全模拟发声链路、确定性仿真。

不做：真实 OBS、TTS、审核模型、决策模型、B 站、VTube Studio、Iris、Game Runtime 及游戏桥。这些在后续阶段接入；P0 只为发声链路需要的部分提供模拟实现（模拟 Stage、模拟 TTS、模拟 L1 审核、回放的模型输出、录制的弹幕、模拟 OBS）。

## 步骤

1. **工程骨架。** 按已批准的 R-01–R-03 建立工作区、类型检查、格式检查、测试和三平台 CI；建立 TypeScript → JSON Schema 的生成管线。
2. **本机通道。** 实现进程间通信抽象：macOS/Linux 用 UDS，Windows 用命名管道；按 R-05 做双向认证，认证先于任何数据；帧长上限与超时。Windows CI 必须实际跑命名管道用例。
3. **进程启动。** 按 R-23 实现启动方式与连接信息分发，按 R-06 实现子进程的启动与停止；看门狗不是宿主的子进程。
4. **插件内核。** 服务与依赖激活、可撤销注册、生命周期（含静止中）、五种事件分发、加载器、profile/patch、普通插件热替换、sidecar 代理。用一个模拟 sidecar 进程验证崩溃后服务撤回与恢复。
5. **状态存储。** 事件表、投影表、意图表、许可令牌；副作用先写意图；在每个写入点注入崩溃并验证重启语义。
6. **安全核。** 执行闸门、审核闸门（L0 规则 + 模拟 L1）、执行许可与令牌、急停（经 OBS 应急连接对接模拟 OBS）、监督模式与自动降级、速率限制；外部看门狗在宿主心跳丢失时对模拟 OBS 执行静音与切场景。
7. **模拟发声链路。** 录制弹幕 → 分诊 → 回放的模型输出 → 分句与双文本 → 审核闸门 → 发声仲裁 → TTS 代理（核验凭证）→ 模拟 TTS（给出合成的时间映射）→ 模拟 Stage（回报播放游标）→ 按游标截断并写回上下文。用“弹幕回复”和“定时播报”两个来源验证按来源定优先级、抢占与截断。
8. **确定性仿真。** `sim` profile 由种子驱动；每一步检查不变量；失败可用“种子 + 提交”复现。

## 出口

以下全部在 macOS 上实际运行通过，且三平台 CI 绿：

**插件内核**
- 依赖消失与恢复、sidecar 崩溃与恢复、热替换失败回退。
- 安全核无法被 profile 移除或禁用。

**安全核与状态存储**
- 没有审核凭证的句子无法进入 TTS；L1 不可用时沉默。
- 执行许可过期或被吊销后，模拟设备拒绝旧令牌的指令。
- 急停后没有新的输出；看门狗在宿主心跳丢失后完成静音与切场景。
- 监督模式的转换、在场确认过期与自动降级符合[安全核](../modules/safety-core.md#监督模式)的规则（用模拟设备验证逻辑，真实输出在 P1 验证）。
- 任一写入点崩溃后重启：状态一致，副作用不重做，执行中的意图标为 `unknown`，许可令牌不回退。

**发声链路**
- 抢占与截断后，上下文只包含模拟 Stage 回报已播出的部分。
- 模拟 Stage：欠载不推进游标；旧令牌的音频被丢弃；收不到宿主心跳时自行静音。
- 分诊：合并、过期、注入降权、称呼净化。
- 决策模型回放：非法输出被丢弃；上下文中不出现被排除的内容。

**仿真**
- 确定性仿真在固定种子集上通过全部不变量。

模拟环境里测得的时延不代表真机表现，真机时延在 P1 实测。
